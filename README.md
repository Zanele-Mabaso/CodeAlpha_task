# CodeAlpha Java Programming Internship: Task Submissions

This repository contains my submissions for the CodeAlpha Java Programming Internship. Each project is in its own folder with its own README, setup instructions and design notes.

## Projects

| Task | Project | Description |
|---|---|---|
| 1 | [Student Grade Tracker](CodeAlpha_StudentGradeTracker) | A Java Swing app for recording student scores and calculating the average, highest and lowest |
| 4 | [Hotel Reservation System](CodeAlpha_HotelReservationSystem) | A Java Swing app for searching, booking, paying for and cancelling hotel rooms, with bookings saved to a file |

## Skills practised

- Object-oriented design in Java: classes, encapsulation and enums
- Separating the model (data and rules) from the user interface
- Building desktop interfaces with Swing
- File handling and persisting data
- Input validation and error handling
- Git and GitHub workflow from the command line

## Running a project

Each folder explains how to compile and run it. In short, you need JDK 11 or later, and from inside a project folder you run `javac` and then `java`. See the project's own README for the exact commands.
